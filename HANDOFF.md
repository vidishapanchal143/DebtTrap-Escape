## Current Implementation Overview

- **Ledger Mock (`src/lib/ledger.ts`)**: Provides an in‑memory SQLite‑like API with `exec`, `prepare`, and a simple `transaction` wrapper. Supports basic wallet operations (`createWallet`, `getWalletBalance`, `createTransfer`, `cancelTransfer`, `confirmTransfer`).
- **Wallet Service (`src/lib/wallet.ts`)**: Uses the ledger to create wallets, prepare simulated USDC transfers, cancel and confirm transfers with safety checks (cannot cancel after confirmation and vice‑versa). Errors are thrown for invalid state transitions.
- **API Routes**:
  - `src/app/api/wallet/prepare/route.ts` – prepares a simulated transfer.
  - `src/app/api/wallet/cancel/route.ts` – cancels a pending transfer.
  - `src/app/api/wallet/confirm/route.ts` – confirms a pending transfer.
  - `src/app/api/agent/route.ts` – placeholder for the Gemini agent endpoint (registered tools will be added later).
- **Testing (`tests/wallet-workflow.test.ts`)**: Validates the wallet workflow including preparation, cancellation, confirmation, duplicate actions, insufficient balance, status checks, and transaction history.
